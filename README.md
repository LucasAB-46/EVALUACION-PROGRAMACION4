🏍️ BLOG FAN DE MOTOGP
🏁 Descripción General del Proyecto
Este proyecto es una aplicación web básica desarrollada para la evaluación de programación, que simula un blog dedicado a las noticias de MotoGP. Su objetivo principal es demostrar la capacidad de integración de HTML, CSS (Bootstrap y Tailwind) y JavaScript para crear una experiencia de usuario dinámica y responsiva.

El blog se compone de tres páginas principales:

Inicio (index.html): Muestra un listado de noticias en formato de tarjetas que se cargan dinámicamente utilizando JavaScript.

Artículo (articulo.html): Ofrece una experiencia de lectura inmersiva con scroll, mostrando el contenido completo del artículo con párrafos, imágenes y citas de manera intercalada.

Contacto (contacto.html): Contiene un formulario funcional con validación de datos en tiempo real implementada con JavaScript.

✨ Características y Requisitos Implementados
Diseño Responsivo Total: La interfaz se adapta correctamente a dispositivos móviles, tabletas y escritorios.

Manejo de Contenido Dinámico: Uso de JavaScript (app.js) para simular la carga de datos (noticias) y la inyección de elementos en el DOM.

Experiencia de Lectura: El detalle del artículo está diseñado para una lectura fluida, cumpliendo con la necesidad de ver texto e imágenes mientras se hace scroll.

Validación del Formulario: JavaScript valida campos requeridos, formato de email y longitud del mensaje en el formulario de contacto.

Estilos Mixtos: Se combinan el sistema de grid de Bootstrap con las clases utilitarias de Tailwind CSS para lograr una estética moderna y profesional.
