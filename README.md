<!-- Descripción del Proyecto -->

Este proyecto es un Blog Temático de MotoGP desarrollado como parte de una evaluación, implementando un diseño limpio y responsivo, centrado en la experiencia del usuario. Simula la carga de noticias dinámicas y presenta un formulario funcional con validación en tiempo real.

✨ Características Principales
📰 Diseño de Lectura Inmersiva: La página de artículo (articulo.html) carga contenido completo (párrafos, imágenes, citas) para ofrecer una experiencia de lectura con scroll vertical (como una lista de lectura).

📱 Totalmente Responsivo: Adaptación completa del layout (tarjetas, menú, formulario) para visualizarse correctamente en dispositivos móviles, tabletas y escritorio.

⚙️ Dinamismo con JavaScript:

Carga dinámica de las noticias en la página principal (index.html).

Manejo de rutas (articulo.html?id=...) para cargar contenido específico.

Validación de formulario en contacto.html.

🎨 Estilos Mixtos: Uso de Bootstrap para el grid y la estructura de componentes, complementado con Tailwind CSS para un estilo moderno y personalizado.

📂 Estructura del Proyecto
La aplicación está organizada en tres carpetas principales para mantener la claridad y la separación de responsabilidades:

.
├── CSS/
│   └── styles.css      # Estilos personalizados.
├── HTML/
│   ├── index.html      # Página de inicio (listado de noticias).
│   ├── articulo.html   # Página de detalle del artículo.
│   └── contacto.html   # Página con formulario y validación.
├── JS/
│   └── app.js          # Lógica de carga de noticias, manejo de rutas y validación.
└── README.md
